# Frontend Agent — Prescription Medication Refill Price Predictor

Follow `PROJECT_PLAN.md`. This agent owns UI/UX only.

- Jinja HTML templates
- CSS design system
- Vanilla JavaScript
- Responsive layout
- Accessibility
- Charts using browser-native SVG/Canvas
- Loading, empty and error states
- Navigation and reusable visual patterns

- Database access
- ML logic
- Authentication rules
- Prediction formulas
- Business rules
- Server configuration
